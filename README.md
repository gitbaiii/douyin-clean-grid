# 抖音精选 · 清爽首页

让抖音精选首页保持整齐的封面网格，减少不必要的视频和直播预览。


## 功能

- 将首页占据多列的大卡片缩为普通封面卡片，保留卡片尺寸供长列表计算。
- 阻止首页鼠标悬停视频预览和直播卡片预览。
- 拦截已识别的视频/直播预加载方式，减少流量消耗。
- 用原有封面显示静态卡片，避免被拦截的播放器错误提示覆盖封面。
- 两个独立开关，设置保存在本机。

## 安装

1. 下载解压到固定文件夹，确认文件夹内直接包含 `manifest.json`。
2. Edge 打开 `edge://extensions`；Chrome 打开 `chrome://extensions`。
3. 开启「开发人员模式」，点击「加载解压缩的扩展」，选择刚才的文件夹。
4. 打开或刷新 <https://www.douyin.com/jingxuan>。

需要 Chromium 111 或更新版本。目前未上架扩展商店。

更新：将新版本解压覆盖原文件夹，在扩展管理页点击「重新加载」，再刷新所有已打开的抖音页面。只重新打开设置弹窗不足以更新网页中的旧脚本。

## 范围和限制

- 主要作用于抖音精选列表页，包括其分类切换；详情页及带 `modal_id` 的详情弹层放行。`live.douyin.com` 的直播间不注入本扩展。
- 不过滤普通广告卡片，不修改账号、推荐算法或平台数据。
- 首页图片、列表接口等照常下载，不承诺「零流量」或拦截全部加载方式。未知 CDN、Worker、WebRTC 等方式可能漏过；已经下载的数据无法撤回。
- 真实点击视频卡片后，短暂放行 3 秒，以兼容详情播放器在地址更新前启动。这段时间也可能放行部分预加载。
- 开关关闭不会自动重试已取消的请求；要完全恢复原页面行为，关闭开关后刷新页面，或卸载扩展后刷新。
- 无可读封面时显示「点击观看」占位。站点改版可能影响功能；拦截悬停也可能影响部分悬停提示。

## 权限与隐私

仅使用 `storage` 保存本地开关，内容脚本匹配 `https://www.douyin.com/*` 以兼容站内切换。全部扩展代码随安装包提供，无远程代码、遥测或上传服务。不读取 Cookie、密码或账号令牌。封面显示沿用页面已有的图片地址，仍受平台自身的数据政策约束。详见 [隐私说明](PRIVACY.md)。

## 开发与验证

```powershell
npm ci --ignore-scripts
npm test
powershell -NoProfile -ExecutionPolicy Bypass -File .\Build.ps1
```

Node.js 22；打包脚本需要 Windows PowerShell 或 PowerShell。依赖仅用于本地测试，不随浏览器扩展发布。`dist/` 包含扩展 ZIP 和 SHA-256 校验文件。每次向 `main` 提交或手动运行 Actions 时先检查、打包；版本号尚无对应 Release 时自动创建测试版 Release，已有版本不覆盖。

隔离测试覆盖布局开关、首页/详情边界、预览及直播加载拦截、静态封面恢复，以及基于当前站点算法的长列表回归。它们不能替代真实账号页面的端到端测试。早期布局已获得使用者反馈，后续修复仍需持续实测；欢迎在 Issues 提供复现步骤、浏览器版本和扩展版本，请先遮住个人信息。
